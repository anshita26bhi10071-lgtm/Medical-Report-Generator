# Medical History Report Generator - Project Statement

## Problem Statement

Medical information can be difficult to organize when it is recorded in
different places or in an unstructured manner. Information such as previous
medical conditions, allergies, medications, surgeries, family history and
current symptoms can be difficult to maintain in a single organized format.

The Medical History Report Generator provides a simple Python-based system
for collecting and organizing medical history information provided by a user.

The system generates a structured medical-history report from the information
entered by the user.

The system does not diagnose diseases or provide medical treatment
recommendations.

---

## Scope

The project supports:

- Adding patient information
- Viewing patient records
- Updating patient records
- Deleting patient records
- Recording medical history
- Recording allergies
- Recording medications
- Recording previous surgeries
- Recording family medical history
- Recording current symptoms
- Recording lifestyle information
- Generating a structured medical-history report
- Storing information in a CSV file

---

## Target Users

The intended users are:

- Students learning Python
- Individuals organizing personal medical history
- Users demonstrating a beginner-level software project
- Students working on healthcare-related software concepts

---

## High-Level Features

### Patient Registration

The system collects basic patient information such as:

- Patient ID
- Name
- Age
- Gender

### Medical History

The system records:

- Previous medical conditions
- Allergies
- Current medications
- Previous surgeries
- Family medical history
- Current symptoms
- Lifestyle information

### Patient Management

Users can:

- View patients
- Update patients
- Delete patients

### Medical Report Generation

The system creates a structured report using the information provided by
the user.

### Data Storage

Patient records are stored in a CSV file.

### Validation

The system performs basic validation of names and ages.
