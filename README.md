Medical History Report Generator

Project Overview

The Medical History Report Generator is a beginner-friendly Python project
that collects and organizes medical history information provided by a user.

The system can store patient information, manage patient records and generate
a structured medical-history report.

Features

- Add patient
- View patients
- Update patient
- Delete patient
- Record medical history
- Record allergies
- Record medications
- Record surgeries
- Record family history
- Record symptoms
- Generate medical report
- CSV data storage
- Input validation

Technologies

- Python 3
- CSV
- Git
- GitHub
